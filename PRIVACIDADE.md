# Política de privacidade do Prumo

*Última atualização: novembro de 2026*

O Prumo é um app de quadros de tarefas para Windows. Esta política explica quais dados ele usa e onde eles ficam.

## Dados que o Prumo guarda

Os quadros, listas, cartões e configurações que você cria ficam **no seu computador**, em `%APPDATA%\Prumo`. O Prumo não tem servidores e não envia esses dados para os desenvolvedores nem para terceiros.

## Sincronização com o Google Drive (opcional)

Se você conectar sua conta Google:

- **O que o Prumo acessa:** apenas os arquivos que ele mesmo cria no seu Google Drive (a pasta "Prumo" e o arquivo `prumo-data.json`), pela permissão `drive.file`. Ele **não vê, não lê e não altera** nenhum outro arquivo seu. Também é usado o seu endereço de e-mail, só para mostrar no app qual conta está conectada.
- **Para onde os dados vão:** direto do seu computador para o seu Google Drive. Não passam por nenhum servidor do Prumo.
- **Onde fica o acesso:** a autorização do Google fica guardada só no seu computador, criptografada pelo Windows.
- **Quem tem acesso:** só você. Os desenvolvedores do Prumo não recebem, não armazenam e não conseguem ver suas informações, sua conta ou seus arquivos.

O uso das informações recebidas das APIs do Google segue a [Política de dados do usuário dos serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de uso limitado.

## Como remover o acesso e os dados

- No Prumo: **⋯ › Google Drive › Desconectar**. O acesso é revogado na hora.
- Na sua conta Google: <https://myaccount.google.com/permissions>.
- Para apagar os dados da nuvem, exclua a pasta "Prumo" do seu Google Drive.
- Para apagar os dados do computador, exclua a pasta `%APPDATA%\Prumo`.

## Atualizações do app

Para saber se há uma versão nova, o Prumo consulta o endereço público de downloads no GitHub. Essa consulta não envia nenhum dado seu.
