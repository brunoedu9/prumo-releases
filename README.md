# Prumo

Quadros de tarefas para Windows: listas, cartões e prazos, com os dados guardados no seu próprio computador.

## Baixar

Vá em **[Releases › mais recente](https://github.com/brunoedu9/prumo-releases/releases/latest)** e baixe o **`Prumo-Setup-<versão>.exe`**.

Depois de instalado, o Prumo se atualiza sozinho: ele avisa quando há versão nova e instala ao reiniciar.

Se o Windows mostrar **"O Windows protegeu o computador"**, clique em **Mais informações** › **Executar assim mesmo**. O aviso aparece porque o instalador ainda não tem assinatura digital.

---

Este repositório guarda só os instaladores e os arquivos de atualização do app.
